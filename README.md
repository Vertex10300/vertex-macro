# Vertex Macro

Windows용 이미지 감지 + 자동 클릭 매크로 도구

## 기능

- **이미지 감지 클릭** — 화면에서 지정 이미지를 찾으면 자동 클릭
  - 감지된 이미지 중앙 클릭
  - 지정 좌표 순차 클릭
  - 다른 이미지를 순차적으로 찾아서 클릭 (체인 매크로)
- **멀티스케일 매칭** — 크기가 약간 달라도 감지 (95%~110%)
- **색상 검증** — 모양이 같아도 색상이 다르면 구별 (엣지 기반)
- **반복 클릭** — 지정 좌표들을 순서대로 반복 클릭
- **스캔 영역 제한** — 특정 화면 영역만 스캔하여 속도 향상
- **단축키** — F1~F12 등 커스텀 핫키 지원

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
python macro.py
```

## 단축키 (기본값)

| 키 | 기능 |
|---|---|
| F1 | 좌표 추가 |
| F2 | 감지 시작/중지 |
| F3 | 반복 시작/중지 |
| F8 | 입력 대상 전환 |
| F9 | 전체 중지 |
| ESC | 종료 |

## 설정

설정 탭에서 스캔 간격, 반복 간격, 정확도, 단축키 등을 조정할 수 있습니다.
설정은 `macro_config.json`에 자동 저장됩니다.
